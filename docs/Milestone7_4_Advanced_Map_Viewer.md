# Milestone 7.4 — Advanced Map Viewer

The main map view can now switch base layers without regeneration, blend exported overlays, adjust overlay opacity, zoom with the mouse wheel, pan with the middle mouse button and reset the view. Left-clicking a map draws a dynamic crosshair and reports canonical cell, longitude/latitude and sampled RGBA values.

Crosshair/overlay graphics are UI-only; they never modify exported PNG files.
