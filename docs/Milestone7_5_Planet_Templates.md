# Milestone 7.5 — Planet Templates & Presets

Eleven coherent templates are available from the dynamic parameter workspace: Earth-like, Archipelago, Supercontinent, Ocean World, Dry World, Frozen World, Mars-like, Venus-like, High Tectonics, Low Relief and Mountain World.

`SMART RANDOM` chooses one template and applies bounded correlated variation instead of independently randomizing every physical control. The legacy full-random button remains available.

Template data is stored separately from the UI in `PlanetTemplates`, so the same values can later be consumed by the standalone frontend and the generator add-on/API.
